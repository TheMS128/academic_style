# Выполнение работы

В событие добавлено поле `discoverer` типа `String?` — автор открытия. Элвис-оператор подставляет строку: выражение `lastEvent.discoverer ?: "неизвестен"` даёт текст для карточки результата. Все три модификатора заданы в EventCard.

Порог свайпа хранится в `swipeThreshold = 200f`, а версия библиотеки `2.2.10` в тексте остаётся кодом.

# Контрольные вопросы

1\. Kotlin; Чем отличается создание списка через listOf(...) от создания через mutableListOf(...)?

Функция `listOf` возвращает список только для чтения, а `mutableListOf` — изменяемый список, в который можно добавлять элементы.

2\. Null-safety; Что делает оператор утверждения не-null (!!) и почему разработчики называют его опасным?

Оператор `!!` превращает значение типа `T?` в `T` и бросает исключение, если значение оказалось null.
