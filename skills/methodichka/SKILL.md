# Methodichka

Собирает **методические указания к лабораторным работам** в .docx в стиле ВлГУ из
одного Markdown-файла. Отличается от скилла `lab-report`: тот делает отчёт одного
студента (с полями ФИО/группа/преподаватель), а этот — учебное издание с простой
обложкой без данных студента.

`<assets>` = `~/.claude/skills/methodichka/assets`. Разовая установка: `npm i` там.
Полиграфические стили (Times New Roman 14, интервалы, заголовки, таблицы)
переиспользованы из `lab-report` (`lib/styles.js`).

## Как рендерить

```
node <assets>/bin/render.js <input.md> <output.docx> --title "Название дисциплины" --year 2026 --author "И. О. Фамилия"
```

`--author` печатает «Составитель И. О. Фамилия» на обложке (необязателен). Обложка —
полная шапка вуза (жирная), название, подзаголовок, составитель; город и год закреплены
рамкой у нижнего края. Раздел/Глава/Подглава — это встроенные «Заголовок 1/2/3», поэтому
поле оглавления `TOC \o "1-2"` собирается в любом Word; документ помечен `updateFields`,
поэтому Word обновляет его при открытии
(или Ctrl+A → F9). Разрыв страницы ставится **только перед «Разделом»** (`#`). Тело
имеет нижний колонтитул с номером страницы (обложка без номера). Таблицы не рвутся
посреди страницы: не помещающаяся целиком переносится на следующую (для очень длинных
таблиц — маркер `%%split`).

- **Обложка** формируется из параметров и `lib/profile.js` (`cover`: университет,
  подзаголовок «Методические указания…», город). Данных студента на обложке нет.
- **Тело** берётся из Markdown после первой строки-разделителя `---`; всё, что выше
  неё, считается заглушкой обложки и в документ не попадает.

Предпросмотр (счётчик страниц по секциям + PNG) — скриптом из lab-report:
`node ~/.claude/skills/lab-report/assets/bin/preview.js <docx> [out.png]`. Раздел 1
(обложка) должен занимать ровно одну страницу. docx-preview не разбивает текст на
страницы как Word, поэтому финальную разбивку смотреть в Word/Word Online.

## Поддерживаемый Markdown

| Разметка | В документе |
|---|---|
| `#` | **Раздел** — по центру, полужирный, с новой страницы, в оглавлении (уровень 1) |
| `##` | **Глава** — по центру, полужирный, без разрыва, в оглавлении (уровень 2); работы: «Лабораторная работа N: «Название»» |
| `###` | **Подглава** — слева, полужирный: «Цель работы», «Задание» и т. п. |
| абзац (можно в несколько строк) | «Основной текст», по ширине, красная строка |
| `1. пункт` / `- пункт` | настоящий нумерованный/маркированный список Word; продолжения пункта на следующих строках присоединяются |
| строка `Таблица: Название` перед таблицей | подпись «Таблица N. Название» по центру (10 пт до, 10 пт после таблицы), автонумерация |
| таблица `\| … \|` | таблица 15 см, фиксированная ширина колонок, шапка повторяется на новой странице |
| строка-маркер `%%split` в таблице | делит длинную таблицу: продолжение с новой страницы под «Продолжение таблицы N. Название» |
| ` ```Название ` … ` ``` ` | подпись «Название:» без отступа, затем листинг; после кода 10 пт |
| `![Название](путь.png)` | рисунок по центру + подпись «Рисунок N. Название» снизу, автонумерация; путь относительно файла .md |
| `> цитата` | обычный абзац (без выделения) |
| `` `код` `` | моноширинный шрифт (для путей и идентификаторов) |
| `---` | разделитель (в теле игнорируется) |

**Выделение (полужирный) — только в заголовках** (через стили). В тексте `**…**`
игнорируется: подгонять абзацы под вид списка нельзя, для перечислений используются
настоящие списки, для «термин — пояснение» — таблицы или проза.

## Правка формата

Всё оформление — в `lib/`. Обложка — `lib/cover.js`; сопоставление Markdown → стили —
`lib/md.js`; полиграфические параметры и данные обложки — `lib/profile.js`; сами стили
абзацев/таблиц — `lib/styles.js`. Другой вуз/шаблон — другой профиль, остальной код не
меняется. Файлы скилла лежат вне репозитория; менять их — только по явной просьбе
пользователя.
