# Statistical / computational labs

Adds to S: the heading is usually `Задание (Вариант N)` (S4) with the whole task statement
from the methodichka — given data, what to determine, significance level, the tool.

## Выполнение работы — short (`МАД_4`)

1. «Для выполнения работы был проведён <метод>, который показан на рисунке {fig:method}.»
2. The figure: the user's screenshot of the tool's output (Excel, Statistica), or a result
   table rendered from a real computation (G5 → Analysis result).
3. One interpretation paragraph: «Результаты анализа таковы: <величина> равна
   <значение>, что говорит о <смысл>. …» — one hedge where the data is uncertain (T14).
4. «Итоги можно увидеть на рисунке {fig:result}.» → the figure.

No listings. Every number comes from a real computation (G1).
