# Coding labs — HTML/CSS/JS, SQL, programs, mobile apps

Adds to S: the assignment is usually a numbered list of largely independent exercises
(`Задания`, S3); each exercise is one block of `Выполнение работы` (S5, S9), optional ones
after the mandatory ones (S8).

## A block

1. Opening — the action or decision the block records: «Класс Man описывает персонажа
   игры четырьмя закрытыми полями …», «Первым добавлен метод Fight, принимающий
   параметром второй экземпляр класса Man …».
2. Implementation paragraphs — impersonal past, perfective: «был использован атрибут…»,
   «было задано два тега…», «была установлена ширина…», «дополнительно указано свойство
   …, что означает, что …». Every tag / attribute / property that matters is named with
   its effect in a relative clause: «атрибут align="Center", который выравнивает
   заголовок по центру страницы». Deprecations and best practice where relevant: «в HTML5
   атрибуты выравнивания использовать не рекомендуется — вместо них применяется CSS».
   A deviation or a problem met on the way — in this block (F3, F4); a production tool —
   where first used, through its consequence (F5).
3. Boilerplate once: `<!DOCTYPE html>`, `<html lang>`, `<head>`, `<meta charset>`,
   `<title>` are described in full in the first exercise only; later ones compress to «В
   теге <html> указан lang="en", в <meta> — charset="UTF-8", в <title> — «Work N».»
4. A sentence naming the file → its listing (B6, B7); several files, several such pairs.
5. Figure paragraph (V5) → figure (G2: console transcript, page render, emulator
   screenshot, real query result).
