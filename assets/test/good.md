# Цель работы

Изучить навигацию в мобильном приложении — это основа дальнейших работ.

# Теоретические сведения

Stack Navigator — это навигатор, который хранит открытые экраны стопкой.

# Словарь предметной области

1. Книга – издание, которое хранится в фонде библиотеки.
2. Читатель – человек, которому выдан читательский билет.
3. Выдача – запись о том, что книга передана читателю.

# Выполнение работы

Переходы между экранами построены на Stack Navigator: по нажатию на карточку в BooksScreen открывается DetailsScreen с данными выбранной книги. Идентификатор книги передаётся параметром маршрута.

Список книг выводит компонент FlatList. Каждая карточка занимает всю ширину экрана и содержит обложку, название и автора; при отсутствии обложки на её месте остаётся серый прямоугольник 80×120. Внешний вид списка показан на рисунке 1.

![Список книг](fig1.png)

| Экран | Компонент | Параметры маршрута |
| --- | --- | --- |
| Список | BooksScreen | нет |
| Карточка | DetailsScreen | bookId |
| Поиск | SearchScreen | query |
| Профиль | ProfileScreen | userId |
| Настройки | SettingsScreen | нет |
