# Выполнение Работы И Анализ

Навигация не просто связывает страницы, а задаёт структуру всего сайта. Меню закреплено сверху, что обеспечивает удобный доступ к разделам. Это позволило добиться требуемого результата.

Был создан файл разметки главной страницы. Была подключена общая таблица стилей сайта. Был добавлен блок основной навигации сайта. Была задана ширина основного контейнера страницы.

Скриншот получен через headless-браузер. Загрузка страницы занимает 0.65 с, что является достаточно быстрым показателем. Почему так? Потому что изображения сжаты.

1. Навигация: реализована через Stack Navigator.
2. Экраны: добавлены два экрана.

| Параметр | Описание |
| --- | --- |
| Цвет | Основной цвет сайта выбран под логотип компании заказчика |
| Шрифт | Для заголовков сайта подобран узкий гротеск без засечек |

## Итоги

1. Изучена структура проекта и его зависимости.
2. Освоена работа с навигацией приложения.
3. Получены навыки вёрстки экранов списка.
4. Разобрана передача параметров в экран.
