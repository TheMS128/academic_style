# academic-style

Плагин для Claude Code со скиллами для учебных и академических текстов на русском языке:
отчёты по лабораторным и практическим работам, методические указания, позже — курсовые
и ВКР.

В основе лежит ядро — правила текста, общие для всех жанров. Скиллы отдельных жанров
правил текста не содержат: они ссылаются на ядро и добавляют только своё — структуру
документа и оформление.

## Установка

Плагин ставится из этого репозитория двумя командами в терминале:

```bash
claude plugin marketplace add TheMS128/academic_style
```

```bash
claude plugin install academic-style@academic-style
```

Скиллы плагина вызываются с его именем: `/academic-style:core`,
`/academic-style:lab-report`. Скиллу `lab-report` для сборки `.docx` нужен Node.js и
разовая установка зависимостей — `npm i` в его папке `assets`.

## Зачем разделение

Раньше правила стиля жили внутри `lab-report` и копировались в его форки. Копии
расходились: одно и то же правило существовало в нескольких редакциях. Теперь у каждого
правила один владелец.

- Правило о том, **как написан текст**, принадлежит ядру.
- Правило о том, **из чего состоит документ и как он выглядит**, принадлежит скиллу жанра.
- Скилл жанра не пересказывает правила ядра. Он может сослаться на правило по id,
  отключить его для своей главы или задать ему другой предел — и только.

## Линейка

| Скилл | Что делает | Зависит от | Состояние |
| --- | --- | --- | --- |
| `core` | Ядро: пишет и правит текст по общим правилам; вызывается и сам по себе | — | есть |
| `lab-report` | Отчёт по лабораторной работе: структура глав, титульный лист, сборка `.docx` | `core` | есть, текст пишет через ядро |
| `practice-report` | Отчёт по практической работе: то же, что `lab-report`, с двумя отличиями | `lab-report`, `core` | запланирован |
| `methodichka` | Методические указания к лабораторным работам из Markdown в `.docx` | `core` | существует отдельно, в плагин ещё не перенесён |

Отличия практической работы от лабораторной:

1. на титульном листе — «Практическая работа» вместо «Лабораторная работа»;
2. главы «Вывод» нет.

Всё остальное `practice-report` берёт у `lab-report` без копирования.

## Что входит в ядро

- **Как писать.** Регистр, конкретика вместо общих слов, ритм абзацев и предложений,
  абзац перед рисунком, ссылки на рисунки и таблицы, письмо из описи фактов, а не из
  черновика.
- **Признаки сгенерированного текста.** Каталог оборотов и построений, по которым текст
  читается как написанный моделью, и способ правки каждого.
- **Списки и таблицы.** Когда содержание действительно требует списка или таблицы, а
  когда остаётся прозой.
- **Факты.** Текст не получает ни одного факта, которого нет в источниках, и не теряет
  ни одного из них.
- **Правка готового текста.** Порядок пересборки текста, который уже существует.
- **Линт текста.** Проверка по обычному тексту, без сборки документа.

## Как скиллы работают вместе

```
запрос «отчёт по лабораторной»
        │
        ▼
   lab-report ── структура глав, опрос, факты проекта
        │
        │  опись фактов + профиль жанра
        ▼
      core ────── текст по правилам ядра, проверка
        │
        │  готовый текст
        ▼
   lab-report ── вёрстка, титульный лист, .docx
```

**Профиль жанра** — короткий файл в скилле жанра. В нём перечислено, что ядру нельзя
трогать (например, «Цель работы» и «Задание» переписываются из методички дословно), в
каких главах какое правило снято и какие пределы отличаются от общих.

Без профиля ядро работает как самостоятельный скилл: принимает текст или набор фактов и
возвращает текст. Так правится курсовая, статья или отдельный абзац — без сборки отчёта.

## Состав репозитория

| Путь | Что там |
| --- | --- |
| `.claude-plugin/` | манифест плагина и запись для установки из репозитория |
| `skills/core/` | ядро |
| `skills/core/SKILL.md` | порядок работы ядра, два режима, формат черновика |
| `skills/core/references/writing.md` | правила V — как написан текст |
| `skills/core/references/layout.md` | правила L — проза, списки, таблицы, текст вокруг листинга |
| `skills/core/references/facts.md` | правила F — что текст вправе утверждать и о чём молчит |
| `skills/core/references/tells.md` | правила T — признаки сгенерированного текста |
| `skills/core/references/rewrite.md` | правка готового текста |
| `skills/core/references/profile.md` | формат профиля жанра |
| `skills/core/profiles/general.json` | профиль по умолчанию: общий академический текст |
| `skills/core/assets/` | линт текста, без зависимостей |
| `skills/lab-report/` | отчёт по лабораторной работе: правила структуры, профиль жанра, сборщик `.docx`, линт документа |

Проверка текста и тесты линта ядра:

```bash
node skills/core/assets/bin/lint.js text.md --profile profile.json
```

```bash
node skills/core/assets/test/run.js
```

## Работа с репозиторием

Изменения попадают в `main` только через pull request из отдельной ветки.
